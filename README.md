# ticketflow

An agent-neutral, ticket-driven delivery workflow for GitHub repos:
ticket, plan, implement, verify, review, merge, handoff.

It is installed into a repo as a canonical `.ticketflow/` folder, with thin
stubs for Claude Code and Codex. You reach it through a Claude plugin, a Codex
plugin, or `START.md` for any other agent.

Why: one workflow, one source, any agent, updated only when you choose to.

## Status

Under construction. v0.1.0 is not released.
